# Valentine's Day Website

Website interaktif untuk merayakan Hari Valentine dengan berbagai fitur menarik.

## Fitur Utama
1. **Countdown Timer** - Hitung mundur ke Hari Valentine
2. **Love Gallery** - Galeri foto dengan lightbox
3. **Love Calculator** - Hitung kecocokan dengan pasangan
4. **Message System** - Kirim dan simpan pesan cinta
5. **Music Player** - Pemutar musik romantis
6. **Dark/Light Mode** - Toggle tema
7. **Responsive Design** - Tampilan optimal semua device

## Cara Deploy

### Option 1: GitHub Pages
1. Buat repository baru di GitHub
2. Upload semua file ke repository
3. Go to Settings > Pages
4. Pilih branch main dan folder /root
5. Save, tunggu beberapa menit
6. Website live di: `https://username.github.io/repository-name`

### Option 2: Netlify
1. Drag and drop folder ke Netlify
2. Atau connect ke GitHub repository
3. Deploy otomatis
4. Dapatkan URL: `https://sitename.netlify.app`

### Option 3: Vercel
1. Import project dari GitHub/GitLab
2. Deploy dengan satu klik
3. Dapatkan URL: `https://sitename.vercel.app`

### Option 4: Hosting Tradisional
1. Upload semua file ke hosting via FTP
2. Pastikan struktur file tetap sama
3. Akses via domain Anda
